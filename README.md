DigitalPublic.com is a technology company focused on providing public data APIs that enable developers to access a wide range of civic, demographic, and governmental information. Their platform aggregates data from multiple public sources, standardizes it, and offers it through RESTful endpoints, supporting use cases such as research, analytics, and application development. The company emphasizes transparency, open data principles, and easy integration for developers building public sector solutions.

**Areas:** Company · Data · APIs · Public · Civic

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for digitalpublic-com: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
